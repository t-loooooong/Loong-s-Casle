# 每日采集（本机运行版）

已通过真实账号21个视频、28个分P的字幕采集；价格匹配已加入标题约束与常见字幕别名。独立发布程序仍需首次 GitHub 授权，尚未完成每天无人值守发布的整条链路验收。

## 首次启用

1. 在 Edge 扩展管理页面找到 SubBatch，点击“重新加载”。不需要重新安装、不增加扩展权限。关掉旧侧栏后重开，会出现“打开每日自动采集”按钮。
2. 点击该按钮打开独立采集页。不要关闭该页。先点击“开始 / 继续检查”，观察第一次运行。下载保存提示要允许自动保存，否则会暂停。
3. 在 GitHub 创建 Fine-grained personal access token：Resource owner 选择 t-loooooong；Only select repositories 仅选 Loong-s-Casle；Repository permissions → Contents → Read and write，其他保持默认。设置合适的到期日，过期后需要重新授权。
4. 双击本文件夹的“首次连接GitHub.cmd”。只在它打开的本机窗口粘贴令牌（不显示字符），按回车。不要发给聊天，也不要写进仓库 / 普通文本文件。程序用 Windows DPAPI 加密到 state/github-token.dpapi，仅此 Windows 用户可解密；不要分享 state 文件夹。这不是抵御同账户恶意软件的保险箱。
5. 双击“开始每日采集.cmd”。已按实际下载位置配置为 Desktop/SubBatchAuto（桌面文件夹），解析最新累计采集包，然后更新 GitHub，触发 EdgeOne 部署。以后位置变更可修改 config.json 的 downloadsRelative，或追加 --downloads="实际下载目录/SubBatchAuto"。

GitHub 令牌入口：https://github.com/settings/personal-access-tokens/new

权限说明：https://docs.github.com/en/rest/git/commits#create-a-commit

## 每天怎么使用

开机、联网 → 打开 Edge 的专用采集页 → 双击“开始每日采集.cmd”。采集页每天北京时间08:17后检查，开晚了会补跑；遇到暂停要处理提示后点击继续。首次检查最近3天，后续按上次完整扫描时间补查，最长回看30天。每轮最多30个分P，达到上限点击继续补采；没有完成完整扫描不会刷新成功时间。

可以使用其他浏览器窗口、办公或看视频，不接管鼠标键盘。不要关闭采集页 / 发布窗口，不要让电脑休眠。转写会占用 CPU/GPU，卡顿时可以取消“无中文字幕时本地转写”，但无字幕视频会暂停而不是假装采集成功。浏览器节能模式可能冻结后台页，不能保证电脑开着就准点执行。

## 安全与准确性

- B站验证、未登录、接口报错、付费专属、超长音频等均暂停，不绕过验证。保留分P断点；重试不重复完成的转写。现阶段单个分P最多30分钟、音频最多8MB；超过需人工处理。
- 只读指定账号的公开视频，所有分P单独保留来源、时间、原文。登录信息仅由原扩展在浏览器内使用，不进入输出包 / GitHub。
- 无歧义的明确报价最多“自动提取”，未核对原视频不算“已核对”。省略币种的口播金额，只有字幕别名和标题等级都能唯一对应时，才作为人民币候选展示，并注明推断。满减、历史价、盒损、售罄、同型号多主价不自动确认；未知型号留在本地审计，不靠猜标题生成公开型号。普通报价与百亿渠道报价分开保留。
- 发布仅修改 data/history.json；每次读取最新分支，冲突重新合并，绝不强制覆盖。保留人工核对和原历史。采集失败不会清空旧报价。
- “推送成功”不等于网站部署完成；需等 EdgeOne 成功部署，再检查 https://loong.edgeone.dev/ 的时间和记录。
- 已知原扩展后台会输出调试日志；不要公开分享其完整日志。

## 文件与恢复

自动包：桌面/SubBatchAuto。审计与去重状态：本目录/state。保留这些便于排错；不要将 state 提交到 GitHub。扩展输出为累计快照，只处理最新一个，避免同一轮下载的28个中间文件触发28次发布。

扩展原始备份：script.js.gunpla-auto-original、background.js.gunpla-auto-original。此前字幕导出补丁的备份也保留。不要删扩展文件夹，解压加载依赖原路径。回滚需关闭扩展、核对备份后恢复这两个文件，再重新加载；不会清空网站历史。
